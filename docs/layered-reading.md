# 分层阅读与阅读反馈

版本：`0.0.1-beta.12`。

## 本轮解决什么

帮助读者先找到概念与解读边界，再按需查看术语解释；让编辑知道内容是否易懂，而不只收到纠错。首先覆盖现有指标专题，血糖作为验证样板；阅读反馈也覆盖器官页。

「快速了解」复用当前发布记录的基础解释和阅读提示；「常见术语，按需展开」把同一记录的指标名称与解释组织为折叠问答。不是 AI 摘要，不新增医学判断，也不承诺每个人都能在 30 秒内理解。完整原句、限制条件和来源引用均保留，没有为追求简短截断句子。读者仍可阅读全文及核对原文依据。

没有对应来源或引用未知来源的段落不出现在快捷阅读区域。没有可用段落时不留空占位。不增加私人画像、阅读打卡或完成度判断。

## 版本与交互

- 快捷区域和正文读取同一份当前公开快照，草稿不会混入；发布、回滚、撤回沿用现有公开页面规则。
- 无独立摘要缓存，无数据库迁移，也没有为本版重新发布现有内容或创建审校记录。
- 页面分别显示来源核对与专业审校状态；引用完整只是工程检查，不等于医学准确性或医生审校。
- 折叠使用原生 `details/summary`，SSR 与无脚本阅读均可用；来源是实际锚点链接。
- 大字号覆盖快捷区。开启本地阅读记录后，可保存「快速了解」「术语问答」章节；不保存某一问题的展开状态，不自动开启记录。

未来如果需要编辑独立摘要、检查准备或常见误区等问答，须增加独立内容字段、来源约束和版本指纹覆盖，并完成专业审校，不能只把前端固定文字当作已审校内容上线。

## 轻量反馈

三种选择：「有帮助」「仍没看懂」「没找到想了解的」。选择本身不发送；读者确认提交说明并点击提交后才请求后台。没有自由文本、报告上传、联系方式或账户要求，不自动保存选择和查询码到浏览器存储。

沿用 `/api/feedback/submit`：只发送固定文案、内容类型/标识/频道、发布版本、确认标识和随机查询码。后台保存查询码哈希，不公开反馈；原来的同源校验、体积限制、版本检查、撤回检查和限流继续生效。本轮没有新建统计或追踪服务。

对应后台分类：

| 感受 | 后台分类 | 用途 |
| --- | --- | --- |
| 有帮助 | 页面使用问题 / `experience` | 编辑参考，不视为医学准确性证明 |
| 仍没看懂 | 表达不易理解 / `clarity` | 发现需改进的解释 |
| 没找到想了解的 | 页面使用问题 / `experience` | 发现可能的内容覆盖缺口，不采集具体健康问题 |

消息统一带「阅读帮助度反馈」前缀，进入现有私有处理队列，可按固定文案查找。现阶段不展示点赞数、满意度百分比，也不声称统计独立人数；没有账号，刷新后重新提交可能是重复反馈。它是编辑信号，不是经过抽样的用户研究。

每次提交前生成随机查询码，网络失败也显示给读者保留。首次发送后锁定选项，重试复用同一完整请求和查询码，避免网络结果不明时重复创建工单；收到成功响应才提示已收到。若内容更新或撤回，提示刷新或停止提交，不向新版本自动转移旧反馈。切换内容版本后表单重新开始。

沿用页面底部「查询纠错进度」查询和删除，持码者拥有相应权限，遗失不能通过身份找回。反馈保留至主动删除或维护者清理，备份副本随备份保留周期清理。与纠错共享限流额度，不提供独立不限次数的投票接口。无脚本时提交禁用；离线演示明确说明不记录选择。

## 验证

```sh
npm run test:guide
node scripts/reading-guide-smoke.mjs
```

浏览器脚本默认访问开发端口 5174；用 `PLAYWRIGHT_BASE_URL` 指定站点，SSR 模式设置 `TEST_SSR=true`。正常模式通过请求拦截检查反馈分支，不写入线上测试反馈。只有隔离预览的本地 3110 端口允许 `READING_FEEDBACK_LIVE=true`，用于验证真实提交、查询与删除。

覆盖逐字复用、引用保留、缺失引用、版本变化、章节白名单、三类固定反馈、提交确认、重复重试、版本冲突/撤回/限流、凭码删除、大字号、320–768px 布局及无脚本问答和来源导航。后台反馈测试在独立测试数据库中验证三类消息实际落库、幂等、查询与删除。

本版验证：38 项前端规则测试、Vite/Next 构建和 TypeScript 检查通过；隔离数据库的 8 组反馈/维护检查、6 组发布渲染检查通过。新阅读反馈也通过隔离预览中的真实浏览器提交、查询与删除。现有静态阅读、继续阅读、搜索、收藏、专题路线、场景入口、分享和主流程回归通过。

分享卡片回归曾间歇性超过默认 5 秒等待，追踪时有仍处于生成状态的情况，尚未确定根因；随后连续三轮通过。图片生成断言调整为 15 秒等待，其余行为断言不放宽。这不是分享性能或真机验收结论。

Docker 部署后，线上分层阅读、模拟反馈、继续阅读、分享和 SSR 主流程回归通过；线上测试不写入正式反馈，真实提交链路仅在隔离测试库验证。现有 8 篇内容、10 条来源、0 条医学审校记录未因本版改变。

## 后续验证

邀请真实读者完成「找到术语 → 复述概念与限制 → 核对来源」任务，观察哪里仍看不懂，再决定是否需要独立摘要与扩展 FAQ。反馈数量不替代理解效果，正式内容仍依赖来源许可核对与合格医学审校。账号、自由问诊、AI 个人报告解读和公开投票榜不属于本版范围。
