# 分享卡片

版本：`0.0.1-beta.11`。

## 读者体验

指标与器官页提供「生成分享卡片」。先获取当前频道的最新公开记录，再使用浏览器 Canvas 生成 1080 × 1440 PNG，支持预览、下载、系统图片分享及复制阅读链接。原有文章链接分享保留。

图片包含标题、简介、审校状态、参考资料数量、内容版本、整理与生成日期、科普提示和二维码。文字限制行数，超长省略；二维码保留四模块留白，并以整数像素绘制。无 JavaScript 时按钮禁用，但 SSR 正文和来源仍可阅读。

系统分享取决于浏览器能力和用户操作，不保证送达目标应用；取消或不支持时提示下载或长按保存。剪贴板不可用时可以选中链接手动复制。微信尚未接入 JS-SDK 自定义分享，长按保存及转发仍需真机验证。

## 内容与隐私边界

- 生成前绕过页面初始快照、静态适配器缓存及浏览器 HTTP 缓存，重新请求当前公开内容。记录不可用或网络失败时不生成旧卡片；重新核对失败会移除已有预览和下载入口。
- 审校状态来自当前公开记录；只有已审校且存在公开审校人信息才显示已完成专业审校。现有内容仍待审校，参考资料数量不代表质量背书。
- 二维码仅含当前站点来源与专题路径，不含查询参数、阅读位置、搜索词、收藏或其他个人信息。不嵌入正文、检查数值或个体化结论。
- 图片使用本机字体和二维码库绘制，不上传图片，不请求第三方制图服务。获取公开内容仍会产生正常站点网络请求；系统分享由用户主动触发。
- 关闭弹窗或重新生成会释放旧图片的临时 URL；此操作不能删除已下载或转发的副本。保存后的图片无法随原文撤回，必须以扫码打开的当前页面为准。
- 当前非 HTTPS 地址有提示，本地开发地址生成的二维码通常不能供其他设备访问。

二维码生成依赖 `qrcode-generator`（MIT）；独立解码验证使用仅开发依赖 `jsqr`（Apache-2.0）。依赖许可不等于本项目已选定开源许可证。

## 验证方法

```sh
npm run test:share
node scripts/share-smoke.mjs
```

浏览器脚本默认访问本地开发服务；使用 `PLAYWRIGHT_BASE_URL` 指定站点，SSR 模式另设 `TEST_SSR=true`。它只读取公开数据，更新/撤回场景通过浏览器请求拦截模拟，不改写线上内容。生成样例保存到被 Git 忽略的 `artifacts/`。

规则测试覆盖强制刷新、字段白名单、干净地址、审校标签、限行与独立二维码解码；浏览器测试对实际 PNG 解码，覆盖下载、公开版本重新核对、失败重试、临时 URL 清理、长文本、器官卡片、焦点返回和 320–768px 布局。系统分享与剪贴板通过模拟浏览器能力验证分支，不代表真实手机或微信验收。

回归中发现禁用 JavaScript 时悬浮收藏栏可能遮挡原生目录链接；现仅在收藏交互就绪后启用悬浮，无脚本阅读时保持普通文档布局。

本版交付检查：33 项前端规则测试、Vite/Next 构建与 TypeScript 检查通过；静态模式的分享、阅读、继续阅读、搜索、收藏、专题路线、场景入口和主流程回归通过。隔离数据库的 6 组发布/回滚/撤回渲染检查，以及 SSR 分享、无脚本阅读、继续阅读和既有主流程检查通过。静态继续阅读首次有一次超时，随后连续三次复测及修复后的回归通过；尚不能据此视为真实设备验收。

Docker 部署后，线上分享、阅读、继续阅读和 SSR 主流程回归通过；实际下载 PNG 的二维码解析为正式站点的专题地址。README 与本文不包含服务器私有部署路径。

真实 iOS Safari、Android Chrome、微信内置浏览器的保存/转发和扫码，以及读者理解与专业医学审校，仍是独立待办。
