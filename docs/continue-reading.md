# 继续阅读与位置恢复

版本：`0.0.1-beta.10`。

## 读者体验

1. 在「收藏 → 最近阅读」主动开启本地阅读记录，默认仍关闭。
2. 阅读指标或器官时，滚动到概念、指标、来源等章节后记录位置，不记录刚打开页面时的顶部位置。
3. 下次打开同一版本时，提示上次章节；点击「继续上次阅读」后定位并把键盘焦点移至目标章节，也可选择留在当前位置。
4. 首页提供最近可用专题的继续阅读入口；收藏页的最近阅读列表显示上次章节。入口打开文章后再确认继续，不把私人阅读位置写进分享链接。

这不是阅读完成度或理解程度判断，不显示百分比、打卡或阅读时长。位置按章节而非像素保存，调字号或换屏幕时不会套用旧滚动高度；它不精确到某一句话。手动目录链接、来源锚点及浏览器自身的前后退行为不被自动恢复覆盖。

## 版本与内容安全

线上以当前公开内容的 `releaseID` 标识版本；静态演示以内容版本及更新时间组合标识。同一版本再次访问保留位置，版本变化后移除旧位置并提示从新版开始。每篇内容仍独立展示来源与真实审校状态。

首页与最近阅读均查询当前频道可用内容，不展示已撤回的旧正文；首页跳过不可用的最近条目。进入正文后才核对版本与位置，首页显示的「上次」章节仅描述历史记录，不保证新版本仍可恢复。网络失败显示重试入口，不把失败当作内容撤回。

## 本地存储与清理

沿用 `zhiyu-reading-v1`，兼容没有位置字段的旧记录。每条记录包含类型、内容 ID、最近访问时间，可选的章节 ID 和内容版本，以及本次访问的本地标识；访问标识仅用于拒绝旧标签页的延迟写入，不发送到服务器，也不是认证凭据。严格限定可存储的章节和字段，不保存标题、正文、报告、搜索词或像素坐标。

滚动停下约 400ms 后保存；页面离开、切换到后台时尝试保存已观察到的位置。没有滚动或目录跳转时，不因页面打开就覆盖旧位置。浏览器强制终止时不承诺最后一次变化一定落盘。

沿用最多 20 条、90 天限制及当前浏览器范围。清空后仍可保持记录开关开启，但已打开页面的滚动不会重新创建被清空的条目，需再次打开文章才产生新的访问记录；关闭同时清空。若另一标签页后来打开同一篇，以新访问为准，旧访问不再覆盖位置。localStorage 不提供跨标签页事务，不承诺完全同时操作时的冲突合并。

SSR 不输出私人位置，禁用 JavaScript 时不展示继续阅读控制，正文和目录依然可用。存储失败沿用风险提示及当前页面的临时状态，不承诺刷新、整页导航后保留；需要时请通过浏览器清除此站点数据。没有新增账号、服务端阅读档案或跨设备同步。

## 验证

- `npm run test:reading`：旧记录兼容、白名单/字段裁剪、版本变化、清空/关闭及访问标识校验。
- `node scripts/resume-smoke.mjs`：默认不记录、主动恢复与焦点、指标/器官位置、首页回访、显式来源链接、版本失效、跨标签清理、不可用条目与移动端布局。
- SSR 检查增加 `TEST_SSR=true`，通过 `PLAYWRIGHT_BASE_URL` 指向测试站点。

本版交付检查：28 项前端规则测试、Vite/Next 构建及 TypeScript 检查通过；静态浏览器的继续阅读、阅读、收藏、专题路线、场景入口、搜索和既有主流程回归通过；隔离数据库的 6 组服务端渲染检查、SSR 继续阅读/阅读体验/既有 SSR 浏览器回归通过。也覆盖了离开页面时保存待写位置，以及旧标签页不能覆盖后来打开的同一篇内容。
