# 阅读体验（0.0.1-beta.5）

## 本轮范围

- 指标文章提供原生目录链接：概念、指标、过程、看报告提示、来源。关闭 JavaScript 时仍可跳转；不隐藏来源或审校状态。
- 指标与器官页提供大字号开关，在当前浏览器记住偏好；重点放大正文、提示与参考来源，不修改医学内容。
- 「收藏」页增加最近阅读。默认关闭，主动开启后才记录成功加载的指标/器官条目，最近访问排在前面。
- 搜索空结果提供可点击关键词建议及非诊断提醒；不保存搜索历史。分享仅使用当前知识页路径，去掉查询参数和目录锚点。

## 本地数据边界

使用独立键 `zhiyu-reading-v1` 保存字号、是否启用记录、条目类型/标识/阅读时间。保留最多 20 条、90 天内记录，重复访问不增加条数；不保存正文、标题、搜索词、报告或账户信息。旧收藏键 `zhiyu-saved` 不变。

进入网站时清理过期或无效记录，浏览器关闭期间不会后台运行清理程序。清空只移除记录并保留开启状态；关闭同时清除记录。更改会同步至同源的其他标签页，不支持跨浏览器或设备同步。

展示最近阅读时会向公开内容接口查询相应 ID 的当前可用摘要，因此服务器仍会收到正常内容请求；不创建服务端阅读档案，也不声称服务器完全看不到访问。撤回或不存在的条目隐藏，不展示本地旧正文。来源及医学审校状态继续由发布快照决定。

SSR 首屏始终使用默认设置，不把某个读者的历史写入 HTML。浏览器加载后恢复本地偏好，所以大字号可能在首屏之后生效。禁用 JavaScript 时阅读目录仍可用，本地记录及字号切换不可用。

存储被禁用或写满时保留当前会话操作并显示提示，不承诺已持久保存或删除旧数据；需要时由读者清除站点的浏览器数据。共用设备不建议开启阅读记录。

## 验证

```sh
npm run test:reading
# 先启动本地开发服务；按实际端口指定测试地址
PLAYWRIGHT_BASE_URL=http://localhost:5173 node scripts/reading-smoke.mjs
# 测试完整 Next.js 站点时，增加无 JavaScript 目录测试
TEST_SSR=true PLAYWRIGHT_BASE_URL=http://localhost:3108 node scripts/reading-smoke.mjs
```

覆盖默认不记录、主动开启、去重排序、记录上限、过期及非法数据清理、不可用条目隐藏、跨标签清空和关闭、存储失败、干净分享、搜索建议与 320/390/768px 大字号布局。配合现有 SSR 和浏览器测试检查收藏、正文与来源兼容。

本轮没有完成场景式首页、经专业审校的分层解释、真实手机/微信分享验收或用户研究；没有数据库迁移或新增医学审校。
