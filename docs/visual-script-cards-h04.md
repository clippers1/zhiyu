## 卡 1 · 血糖（`indicator/glucose`）

| 字段 | 内容 |
| --- | --- |
| 唯一问题 | 血糖检查观察的是身体里哪一段「糖的处理过程」？（不解释诊断标准、不画数值尺） |
| 核心说法与依据 | 1. 食物中的碳水化合物消化后形成葡萄糖——来源 `diabetes`（NIDDK What Is Diabetes?，葡萄糖与胰岛素概述）。2. 胰腺分泌的胰岛素帮助葡萄糖进入细胞供能——来源 `insulin`（NIDDK Insulin Resistance & Prediabetes，「胰腺分泌胰岛素，肌肉、脂肪与肝脏对胰岛素的响应」）。3. 肝脏像仓库一样储存或释放糖——来源 `diabetes` + `insulin`。分镜 3–4 步，每步一句话，超出以上三条直接依据的说法删去。 |

## 卡 2 · 血压（`indicator/pressure`）

| 字段 | 内容 |
| --- | --- |
| 唯一问题 | 血压单上的两个数字（收缩压/舒张压）分别对应心跳周期的哪一段？（不画红绿高低、不做个人结果判断） |
| 核心说法与依据 | 1. 心脏收缩泵血，血液对血管壁产生压力——来源 `hypertension`（WHO，收缩压、舒张压定义与反复测量）+ `heart`（NHLBI，心脏泵血与氧气、营养运输）。2. 血管阻力和血容量影响压力大小——来源 `hypertension` + `kidney`（NIDDK，过滤血液、调节水盐）。3. 规范测量姿势与休息条件让读数可比——来源 `bp`（NLM MedlinePlus，测量姿势、袖带、休息时间）。分镜 3–4 步，每步对应上述来源定位后才能进入绘制。 |
| 视觉元素 | 两部分读数卡：「心脏收缩时」对应收缩压、「心脏舒张时」对应舒张压，配已授权心脏底图（`/media/heart-servier.png`）静态示意；用「收缩/舒张」文字标签而非动画；不用红绿色带表示高低；袖带部分可用简单线稿示意（非医学人体图，可自绘）。 |
| 适用与省略 | 适用：一般成年读者读懂血压单的两个数字。省略：高血压分级阈值、家庭血压目标值、儿童/孕妇标准——省略后页面继续用正文「不能仅凭这一项判断」提示；不使用任何「正常值」刻度。 |

## 卡 3 · 血脂（`indicator/lipids`）

| 字段 | 内容 |
| --- | --- |
| 唯一问题 | 血脂单里几个名称分别对应血液中运输脂类的哪些「包裹」？（并列术语卡，不画血管堵塞图） |
| 核心说法与依据 | 1. 脂类需要搭乘脂蛋白在血液中运输——来源 `lipids`（NLM MedlinePlus，LDL、HDL、总胆固醇、甘油三酯及综合风险评估）。2. LDL 与 HDL 是不同种类脂蛋白，分工不同（正文「常用指标」逐条与来源 `lipids` 对应）。3. 过多 LDL 增加动脉粥样硬化风险为正文已有表述，图上只用文字陈述，不画斑块/堵塞示意。分镜 2–3 步。 |
| 视觉元素 | 并列术语卡（复用指标卡样式）：每张卡一个名称 + 一句话分工；可用简化的圆形「脂蛋白」示意（自绘，非人体结构），标注「示意非真实形态与比例」；不用箭头暗示「好/坏」流向；不使用血管横截面图。 |
