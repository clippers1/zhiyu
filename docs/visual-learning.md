# 可视化互动首期：心脏与血液循环

更新：2026-09-19。实现版本：`0.0.1-beta.13`。P0 发布规则和 P1 互动样板已实现，P2 真实设备与读者验证待完成。属于 [新路线图](roadmap.md) 的 P0–P2，产品定位见 [产品规划](product-plan.md)。

## 1. 为什么选这个样板

现有内容已有心脏和肺，循环过程适合用空间关系与步骤展示，可以验证“互动是否比纯文字更容易理解”。复用已有器官入口，不先新建大量文章。

首期只回答：血液怎样经过心脏与肺并进入全身循环？几个主要结构如何连接？图中哪些是方便理解的简化？

以上是待寻找依据并核对的教学问题，不凭本文直接编制医学结论。选题若缺少可用来源或可维护的表达方式，先缩小范围，不为赶进度编造内容。

## 2. 范围与非目标

包含：静态结构示意、点击部位的简短解释、连贯的分步路径、播放/暂停/前后步骤、同步文字、具体来源、少量带解释的理解题。

不包含：疾病模拟、诊断、治疗、心率/血压/报告输入、个体化风险、真实生理参数计算、精确解剖教学、3D、视频、积分和学习账号。

示意图需清楚标注朝向、左右参照及非真实比例；颜色/运动仅为辅助，箭头、标签和文字要独立表达含义，避免用颜色传达唯一信息。动画速度不能被读者误解为真实血流速度或心率。

## 3. 读者路径

1. 从现有心脏页或专题入口进入，看到学习问题和静态总览，不自动播放。
2. 点选结构，图上高亮与文字解释对应，操作不依赖鼠标悬停。
3. 选择“分步了解”，每一步只强调一个关系；可前后切换、暂停或重新开始。
4. 看完整体过程后，回答 2–3 个依据正文设计的概念题，立即查看解释与出处；允许跳过，不打健康分、不保存答题数据。
5. 查看图示依据与简化说明，打开器官详解、收藏或分享给他人。

首期优先复用现有心脏内容身份与页面；是否增加独立专题路由在实现时按实际数据模型决定。不新增路由只为制造页面数量，也不破坏现有链接和收藏。

## 4. 先做脚本，再做动画

### 4.1 最小来源映射表

每个脚本段和视觉关系都填写下表。以下为空模板，不代表已有来源核对结果。

| 知识点/图形步骤 | 来源标题、机构与 URL | 原文定位、版本/日期 | 本次使用与许可依据 | 中文表达与示意简化 | 核对人、日期与疑点 |
| --- | --- | --- | --- | --- | --- |
| 待填写 | 待填写具体页面，不用机构首页代替 | 章节/图表/锚点；原文无日期则注明 | 自行组织表达、原创示意或获授权素材，分别说明 | 说明省略了什么，是否影响理解 | 仅记录真实核对；有疑点不进入发布 |

优先复核现有来源中与心脏/循环直接相关的材料，再按缺口寻找权威基础教育资料；不声称来源库已有的每条资料都适合本专题。保留原文边界，翻译专业词时核对含义，遇到冲突不按搜索排名自动选用。

### 4.2 脚本产物

- 学习目标与不回答的问题。
- 结构标签表、位置参照、关系/方向表及对应来源。
- 每步的短文字、高亮对象、路径、进入/退出状态和引用编号。
- 图示简化说明、完整静态文字稿与理解题答案依据。
- 素材清单及来源/许可记录；没有许可的图片不直接描摹或转载。

维护者先用静态分步图对照脚本核对方向、顺序、标签和含义，再加入动画。自动测试可以检测预设的路径顺序，不能替代对路径本身的事实核对。

## 5. 实现约束

- 优先 SVG + React，先落地一个专题再提取复用组件；不先搭动画 CMS 或可视化编辑器。
- 医学文字、步骤含义与引用绑定内容版本；图形代码负责绘制，稳定标识连接结构和步骤。初期若脚本随代码管理，也须关联核对记录和发布版本，不让 JSX 成为来源不可追溯的内容库。
- 正文、步骤说明、简化边界和来源由 SSR 输出；无 JS 时仍可读完整图文，不能只剩空画布。
- 默认静止，用户主动播放；尊重 `prefers-reduced-motion`，减少动态效果时提供静态分步而非强制播放。切换页面或组件卸载停止计时，快速连点不产生多套动画任务。
- 按钮有可读名称和当前状态，键盘可操作、焦点可见；不依赖颜色、悬停或拖拽作为唯一操作。读屏不跟随动画每帧播报。
- 移动端同时能找到图示与当前解释；大字号不遮挡控制，支持纵向阅读。
- 复用来源、反馈、收藏和分享，不记录用户答案或健康数据。图示版权未核对前不导出包含该图的分享素材。
- 图文、API、分享卡片与当前发布修订保持一致；撤回后不能继续从新入口取得内容，已下载图片仍无法远程删除。

## 6. 验收清单

### 内容与发布

- [x] 学习目标、脚本、图示关系和理解题都有可核对依据。
- [x] 来源使用方式已记录，SVG 为项目自绘；简化边界明确，没有诊断/治疗或个体化判断。
- [x] P0 来源整理发布路径通过隔离测试，展示未冒用专业审校。
- [x] 旧内容不自动转状态，发布/回滚/撤回及版本绑定检查通过。

### 交互与技术

- [x] 每个可选结构都有对应说明，无空白热点；图文高亮一致。
- [x] 播放、暂停、前后步骤、重置及结构切换通过浏览器回归。
- [x] 320–768px、键盘、减少动态效果和 SSR 无 JS 静态文字稿已实现并纳入检查。
- [x] 内容直达/刷新、来源跳转、收藏/分享及发布撤回沿用现有链路并完成自动回归。
- [x] 首期未引入视频、3D 运行时或新的行为追踪。
- [ ] iOS Safari、Android Chrome 和微信真实设备检查；模拟浏览器测试不能冒充真机结果。

### 用户理解

- [ ] 邀请 5–8 位自愿读者，不收集病史或报告，观察结构查找、步骤控制、路径复述、来源查找。
- [ ] 预先固定任务和答案要点，图文与交互比较时交替顺序，记录提示次数与困惑。
- [ ] 小样本操作目标至少 4/5 无提示完成；理解效果先形成基线，重大误解先修复，不把样本结果包装成统计结论。
- [ ] 记录互动比静态图文真正多解决了什么；若无明显价值，简化交互而不是增加动画。

缺少真实参与者时，工程验收和实验性 Beta 可以分别记录，但不得勾选真实理解验收完成。

## 7. 样板之后

第二主题候选为“呼吸与气体交换”，因为可与心脏循环衔接；是否采用以来源、样板反馈和制作成本为准。血糖与胰腺保留为后续候选，避免直接延伸到用药和个体化代谢判断。

视频仅在反馈证明需要连续演示、交互不适合或特定解释难以表达时补充。每条视频都需字幕、文字稿、来源及素材授权，默认不自动播放，并提供低带宽替代内容。
