# 知愈设计规范 2026 · 清爽极简科技医疗风

更新：2026-11-24 · **本文件定义页面结构与视觉规范，不改变产品范围。**产品做什么/不做什么仍以 [产品蓝图](product-blueprint-2026.md) 为准；全站 18 张 AI 生成插图元数据与溯源清单见 [docs/media-manifest.json](media-manifest.json)。

## 1. 视觉方向：清爽极简科技医疗风

从早期“满屏绿”和过渡期“素颜发丝线纸本”迭代而来，当前视觉建立四条清晰规则：

- **纯白通透 + 利落冷灰阶**：主底纯白 `#FFFFFF`，次级舞台与信息区极浅冷灰 `#F6F8FA`，关键内容使用 `1px solid #E6EBF2` 描边 + 轻柔阴影圆角白卡（`16px` / `20px`）抬起，形成清晰呼吸感。
- **理性医疗青绿为主强调**：主色 `#0F766E`（Teal-700），浅底 `#F0FDFA`；警示与医学边界统一使用琥珀色 `#B45309` + `#FFFBEB`，避免用大面积色块堆砌“医疗感”。
- **零字体包袱的系统无衬线排版**：移除 2.6 MB 打包字体与手绘字体子集构建，采用现代清晰无衬线系统字体栈，正文 16px、行高 1.78–1.85，数字等宽对齐（`tabular-nums`）。
- **全量统一画风的微立体 3D GPT 插图 + HTML 图例**：全站 9 篇指标（10 张）、2 篇故事、`/guide` 报告单静物和 5 张透明底器官特写全部由 `gpt-image-2.6` 按统一 Style Bible 生成并经 `sharp` 转为 WebP（单张 12–65 KB）。画面严格零文字、零数值；所有医学标签、编号图例（①②③④）、来源引用与图示边界全部留在 HTML 中，保证可读性、无障碍与零错别字。

## 3. 信息架构

```text
读体检单 /                    一篇指标主推 + 项目索引 + 身体与日常 + 身体入口
├── 单子怎么读 /guide         四列结构图 + 区间与记号说明 + 按项目找行名
├── 体检项目 /indicators      搜索 + 分类 + 全部项目索引（01–09）
│   └── 图文详情 /article/:id  标题 → 一句回答 → 不能仅凭此项判断 → 单子上的位置 → 插图
│                              → 它是什么 → 分工 → 过程 → 来源 → 内容边界 → 下一篇
└── 认识身体 /organs/:id      器官插图 + 说明 + 互动图解 + 关联项目
```

导航固定三项：**读体检单 / 体检项目 / 认识身体**。`/guide` 属于「读体检单」，进入后导航高亮仍停在第一项，不新增第四个入口。不再出现"收藏""继续阅读"入口——这两个功能在 `b0c5f0a` 已从代码移除。`/saved` 路由保留为兼容入口并渲染首页，但不再作为功能承诺写进 README。

旧链接不变：`/`、`/article/:id`、`/indicators`、`/organs/:id`、`/topics` 全部保留；`/guide` 是本轮新增的单例页面。`/saved` 继续兼容到首页，但不再作为功能承诺写进文档。

## 4. 页面规范

### 4.1 首页（读体检单）

| 顺序 | 内容 | 规则 |
| --- | --- | --- |
| 1 | 页头 | 品牌 + 搜索图标；粘顶，1px 下边线 |
| 2 | 栏目标签 | `读体检单 / 从一张单子读起`，11px、字距 0.2em |
| 3 | 主张 | 衬线 30px（桌面 48px），最多 2 行 |
| 4 | 导语 | 15/17px，一行说清"这里有 9 个项目、讲什么" |
| 5 | 主推一篇 | 固定为指标长文，优先 `featured`，否则编号最小者。编号 + 英文名 + 问题式标题 + 一句话回答 + 该篇第一张自制机制图（含图注与「知愈自制示意图」）+ "读这一篇" |
| 6 | 按项目读 | 除主推外的全部指标（最多 8 条）；更多内容进项目页 |
| 7 | 身体与日常 | 故事索引（最多 3 条），行首标签为「长文」；没有故事时整段消失 |
| 8 | 认识身体 | 器官行，左侧 64px 插图缩略（桌面在右栏） |
| 9 | 页脚 | 科普声明 + 来源核对状态 |

主推篇只能来自已发布内容；无内容时整段消失，不出现空卡或占位。故事永不主推，只出现在「身体与日常」；同一篇在首页只出现一次。主推配图必须是该篇正文的同款内联机制图，不用器官外形插画——读者看到的第一张图要回答「这篇文章解释什么」。桌面为「正文列 + 330px 右侧栏」：右栏固定放身体入口与"这里是什么"，不再重复正文列表。

### 4.2 体检项目页

搜索框置顶，下面一行横向滚动的分类胶囊（选中为实心绿，未选中为描边）。列表是**索引式**：编号、问题式标题、`项目 · 英文名 · N 份来源`。分页保留现有游标逻辑。

### 4.3 图文详情页

详情页有两种版式，由内容包里的 `format` 决定（`kind: story` 一律为长文）：

**词条版式**（`format: entry`，暂无指标使用，保留给只承担查表功能的短条目）：

1. 栏目标签（编号 / 项目名 / 英文名）
2. 问题式 H1（衬线 30px）
3. 一句话回答（17px）
4. **不能仅凭这一项判断**：左侧 2px 赭色线 + 浅赭底，带引用角标
5. 它是什么 / 一组指标各有分工 / 身体里发生的过程
6. 知识来源（机构、标题链接、核验日期）

**长文版式**（`format: article`，现有 9 篇指标与全部故事）：

1. 栏目标签（指标为「编号 / 项目名 / 英文名」，故事为「身体与日常 / 长文」）
2. 问题式 H1
3. 一句话回答
4. **不能仅凭这一点判断**（故事用此措辞）：赭色线 + 浅赭底，带引用角标
5. 首图（未被任何分节认领的图解）
6. 分节正文：`一 / 二 / 三…` 小标题、带引用角标的段落，分节可挂一张图解
7. 常见项目与分工（仅指标长文）
8. 常见问题（`<details>`，来自内容包 `faq`，不再由指标说明自动生成）
9. 知识来源 → 内容边界 → 继续读 → 下一篇

长文页的锚点顺序固定为 `#article-reminder` → 首图 → 正文分节，测试依赖该顺序。
8. 内容边界（浅绿底说明块 + 来源核对状态）
9. 下一篇

来源、图注、边界声明与正文同版本；撤回即整页 404。

### 4.4 认识身体

器官横向切换保留；插图在上、说明在下；互动图解（心脏循环、肺部气体交换）保留现有实现，但外层样式改为纸面规则：无卡片阴影，图解区域用 1px 边框界定。

| 令牌 | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--paper` | `#F7F5EF` | 页面底色 | — |
| `--surface` | `#FFFFFF` | 输入框、需要抬起的单块 | — |
| `--ink` | `#1A241E` | 标题、正文主色 | 14.65:1 on paper |
| `--ink-2` | `#46544C` | 正文次级、导语 | 7.32:1 |
| `--ink-3` | `#667268` | 元信息、图注、编号 | 4.62:1 |
| `--rule` | `#E4E0D5` | 发丝分隔线 | — |
| `--rule-strong` | `#D3CEC0` | 输入框描边、主分隔 | — |
| `--accent` | `#2C6246` | 链接、当前项、强调 | 6.55:1 |
| `--accent-deep` | `#1F4A34` | 强调文字加深 | — |
| `--accent-wash` | `#E7EEE6` | 内容边界说明块 | — |

### 5.2 字阶（9 级，无中间值）

| 令牌 | 手机 | 桌面 | 用途 |
| --- | --- | --- | --- |
| `--t-11` | 11 | 11 | 栏目标签、编号标签、图注授权、页脚 |
| `--t-13` | 13 | 13 | 元信息、图注、按钮小字 |
| `--t-15` | 15 | 15 | 正文、列表标题、输入框 |
| `--t-17` | 17 | 17 | 回答、指标说明、桌面导语 |
| `--t-20` | 20 | 20 | 区块标题、下一篇 |
| `--t-24` | 24 | 24 | 详情 H1（手机）、桌面品牌字 |
| `--t-30` | 30 | 30 | 首页主张（手机）、详情 H1（桌面） |
| `--t-38` | — | 38 | 页面大标题 |
| `--t-48` | — | 48 | 桌面首页主张 |

正文行高 1.85–1.9；标题 1.3–1.5；字距：中文标题 0.01em，全大写标签 0.2em。**禁止 9px、10px、11.5px、12.5px 这类中间值**，原先 40 种字号收敛为 9 种。

### 5.3 间距（8 基数 + 4 半档）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`（`--s-1` … `--s-24`）。页面左右留白：手机 20px，桌面 40px。

### 5.4 形状

- 圆角只有两种：输入框/说明块 `4px`，胶囊 `999px`。不再使用 8/10/12/13/14/16/20/22/26px。
- 无阴影、无渐变、无毛玻璃。层级只靠色阶与 1px 线。
- 触控目标 ≥ 44×44px。

### 5.5 图标与插图

- 图标统一 Lucide，默认 `stroke-width: 1.7`，尺寸 15/17/20/21。
- 器官插图使用现有 `public/media/*.png`，不裁切、不改色；必须带 `alt` 与图注授权。
- 分享卡片沿用现有实现，配色改用本节令牌。

## 7. 响应式与无障碍

- 断点：`≤768px` 手机（单列、TabBar），`769–1100px` 平板（单列、页头居中），`≥1101px` 桌面（正文列 + 330px 右栏）。
- 320px 起不横向溢出；放大字号到 200% 时结构不塌。
- 所有正文颜色对比度 ≥ 4.5:1；发丝线不承担唯一信息载体。
- 焦点环 2px `--accent`，偏移 2px；动效遵循 `prefers-reduced-motion`。
- 无 JS 时正文、目录、来源可直接阅读。

## 9. 长文版式的取舍

- **图解是内联 SVG，不是图片文件。** 外部 SVG 无法使用页面的 `@font-face`，中文标签会回退到设备字体；内联 SVG 还能让文字可选中、可被屏幕阅读器读取。图注、简化边界和来源角标与图片方案一致。
- **图是竖排窄幅的，不是横版课件。** 画布固定 360 单位宽，320px 视口下缩放约 0.78，图内字号下限 14 单位（约 10.9px），所以标签在小屏上仍然可读。分支关系画成「主干→左肘→逐行的箭头」而不是并排三列，长解释一律放图注；`figure-smoke` 会在 320px 下断言字号与画布溢出，防止退回小字横版。
- **单子层回答的是「这一列是什么」，不是「我的结果好不好」。** `/guide` 的四列结构图不含真实项目名、数值、单位或区间，编号图例与说明放在 HTML 里而不是图内；箭头只作为报告单的排版口诀出现，引用只挂在「区间外不一定代表疾病」这类已核来源上。文章里的「单子上的位置」小条只列行名并链回 `/guide`，不重复来源，因此不改变各篇的来源数量与引用编号。
- **目录只列分节，不列每个段落。** 长文最多 5 节 + 附录，目录因此控制在 7 项以内；超过 9 节需要重新考虑信息架构，而不是继续加链接。
- **「常见问题」必须是真的问题。** 内容规则禁止 `如何理解…？` 这类由指标名称自动生成的问句，也禁止答案与正文逐字重复。
- **故事不使用指标模板。** 故事页没有指标分工和过程链，正文更早出现第一张图；它靠叙事推进，而不是套用统一五段。

## 10. 与产品蓝图的关系

本规范不新增功能，只重排既有内容与既有能力：不引入评论、账号、推荐算法、无限流，也不新增医学结论。蓝图中的"首页主推一篇 + 相关作品"由 `FeatureEntry` + `IndexRow` 承载；"手机先单列"由断点规则保证；"不先上多栏底栏"沿用现有 3 项导航。
