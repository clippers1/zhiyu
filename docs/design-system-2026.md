# 知愈设计规范 2026 · 纸本索引

更新：2026-10-27 · **本文件定义页面结构与视觉规范，不改变产品范围。**产品做什么/不做什么仍以 [产品蓝图](product-blueprint-2026.md) 为准；本文只回答"长什么样、怎么组织、怎么实现"。

可交互设计稿：[`design-demos/next/direction-d.html`](../design-demos/next/direction-d.html)（手机发现页 / 图文详情 / 项目索引 + 桌面发现页，文案与编号均取自 `public/content` 真实内容）。

## 1. 为什么重做

现有界面的问题不是"不够漂亮"，而是三条规则没有建立：

| 问题 | 现状 | 后果 |
| --- | --- | --- |
| 颜色没有主次 | 5 个 CSS 文件里 223 个写死的十六进制色值；绿色同时用于品牌、正文、按钮、背景 | 满屏绿，医疗感靠色块堆出来，重点反而看不见 |
| 字号没有级差 | 40 种不同字号（7px–34px）；首页正文 15px、卡片摘要 15px、元信息 13px 挤在一起 | 读者不知道该先读什么 |
| 形状没有秩序 | 23 种圆角、卡片套卡片、阴影叠加；桌面与手机是两套排版语言 | 页面像多个时期拼起来的 |

另外有四处实现与设计意图不符，需要一并修掉：

- **中文无衬线字体从未注册。** `public/fonts/noto-sans-sc.woff2`（1.1 MB）没有任何 `@font-face` 引用，只有衬线体注册了；中文正文实际取决于用户设备。
- **`mobile.css` 的 Direction C 令牌层是死代码。** `@layer zhiyu-c` 内的 `--zc-line: var(--zc-line)` 是自引用，且分层规则整体输给未分层的 `styles.css`，这一层从未生效。
- **图文详情重复两个分享入口。** `.article-share-entry` 与吸底 `.reading-actions` 同时渲染"生成分享卡片"。
- **`BodyArt.jsx` 已无任何引用**，仍随构建进入产物。

## 2. 设计概念：纸本索引

知愈不是 App，是一本**带索引的身体读本**。这个比喻决定了全部取舍：

- **纸是底，不是绿。** 背景是纸色，绿色只做唯一强调色（链接、当前项、强调标记），不铺大面积色块。医学感来自克制的排版和真实的插图，不来自"健康绿"。
- **用发丝线组织层级。** 列表用 1px 线分隔，不用卡片套卡片；全站无阴影、无渐变。
- **编号就是封面。** 现有内容没有封面图，硬凑卡片会显得空。数据里已有的 `number`（01–09）作为产品签名，让每条内容都立得住。
- **插图是唯一大图。** 五张 Servier Medical Art（CC BY 4.0）器官插图不加框、不加底色，直接浮在纸上；授权信息始终跟随图注。
- **标题用衬线，正文用无衬线。** 衬线承担"读物"气质，无衬线承担长文可读性。桌面与手机使用同一套字阶，只调字号，不换字体。

## 3. 信息架构

```text
发现 /                        编辑推荐：一篇主推 + 按项目索引 + 身体入口
├── 体检项目 /indicators      搜索 + 分类 + 全部项目索引（01–09）
│   └── 图文详情 /article/:id  标题 → 一句回答 → 不能仅凭此项判断 → 插图
│                              → 它是什么 → 分工 → 过程 → 来源 → 内容边界 → 下一篇
└── 认识身体 /organs/:id      器官插图 + 说明 + 互动图解 + 关联项目
```

导航固定三项：**发现 / 体检项目 / 认识身体**。不再出现"收藏""继续阅读"入口——这两个功能在 `b0c5f0a` 已从代码移除。`/saved` 路由保留为兼容入口并渲染发现页，但不再作为功能承诺写进 README。

旧链接不变：`/`、`/article/:id`、`/indicators`、`/organs/:id`、`/topics` 全部保留。`/saved` 继续兼容到发现页，但不再作为功能承诺写进文档。

## 4. 页面规范

### 4.1 发现页

| 顺序 | 内容 | 规则 |
| --- | --- | --- |
| 1 | 页头 | 品牌 + 搜索图标；粘顶，1px 下边线 |
| 2 | 栏目标签 | `发现 / 身体与日常`，11px、字距 0.2em |
| 3 | 主张 | 衬线 30px（桌面 48px），最多 2 行 |
| 4 | 导语 | 15/17px，一行说清"这里有 9 个项目、讲什么" |
| 5 | 主推一篇 | 优先故事/长文（标签为「长文」），否则编号 + 英文名 + 问题式标题 + 副标题 + 器官插图 + "读这一篇" |
| 6 | 长文 | 除主推外的长文与故事索引（最多 3 条），行首标签为「长文」；没有长文时整段消失 |
| 7 | 按项目读 | 词条式指标索引（最多 6 条），行内：编号 / 问题 / 项目·成分·来源数；更多内容进项目页 |
| 8 | 认识身体 | 器官行，左侧 64px 插图缩略 |
| 9 | 页脚 | 科普声明 + 来源核对状态 |

主推篇只能来自已发布内容；无内容时整段消失，不出现空卡或占位。长文与故事优先进入「长文」索引；索引最多 3 条，放不下的长文回到「按项目读」，同一篇在首页只出现一次。桌面为「正文列 + 330px 右侧栏」：右栏固定放身体入口与"这里是什么"，不再重复正文列表。

### 4.2 体检项目页

搜索框置顶，下面一行横向滚动的分类胶囊（选中为实心绿，未选中为描边）。列表是**索引式**：编号、问题式标题、`项目 · 英文名 · N 份来源`。分页保留现有游标逻辑。

### 4.3 图文详情页

详情页有两种版式，由内容包里的 `format` 决定（`kind: story` 一律为长文）：

**词条版式**（`format: entry`，暂无指标使用，保留给只承担查表功能的短条目）：

1. 栏目标签（编号 / 项目名 / 英文名）
2. 问题式 H1（衬线 30px）
3. 一句话回答（17px）
4. **不能仅凭这一项判断**：左侧 2px 赭色线 + 浅赭底，带引用角标
5. 它是什么 / 一组指标各有分工 / 身体里发生的过程
6. 知识来源（机构、标题链接、核验日期）

**长文版式**（`format: article`，现有 9 篇指标与全部故事）：

1. 栏目标签（指标为「编号 / 项目名 / 英文名」，故事为「身体与日常 / 长文」）
2. 问题式 H1
3. 一句话回答
4. **不能仅凭这一点判断**（故事用此措辞）：赭色线 + 浅赭底，带引用角标
5. 首图（未被任何分节认领的图解）
6. 分节正文：`一 / 二 / 三…` 小标题、带引用角标的段落，分节可挂一张图解
7. 常见项目与分工（仅指标长文）
8. 常见问题（`<details>`，来自内容包 `faq`，不再由指标说明自动生成）
9. 知识来源 → 内容边界 → 继续读 → 下一篇

长文页的锚点顺序固定为 `#article-reminder` → 首图 → 正文分节，测试依赖该顺序。
8. 内容边界（浅绿底说明块 + 来源核对状态）
9. 下一篇

来源、图注、边界声明与正文同版本；撤回即整页 404。

### 4.4 认识身体

器官横向切换保留；插图在上、说明在下；互动图解（心脏循环、肺部气体交换）保留现有实现，但外层样式改为纸面规则：无卡片阴影，图解区域用 1px 边框界定。

## 5. 设计令牌

### 5.1 颜色

| 令牌 | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--paper` | `#F7F5EF` | 页面底色 | — |
| `--surface` | `#FFFFFF` | 输入框、需要抬起的单块 | — |
| `--ink` | `#1A241E` | 标题、正文主色 | 14.65:1 on paper |
| `--ink-2` | `#46544C` | 正文次级、导语 | 7.32:1 |
| `--ink-3` | `#667268` | 元信息、图注、编号 | 4.62:1 |
| `--rule` | `#E4E0D5` | 发丝分隔线 | — |
| `--rule-strong` | `#D3CEC0` | 输入框描边、主分隔 | — |
| `--accent` | `#2C6246` | 链接、当前项、强调 | 6.55:1 |
| `--accent-deep` | `#1F4A34` | 强调文字加深 | — |
| `--accent-wash` | `#E7EEE6` | 内容边界说明块 | — |
| `--clay` | `#8A4E2C` | 风险提示、来源待核对标记 | 6.01:1 |
| `--clay-wash` | `#F3E9E1` | 提示块底色 | — |

规则：**一屏只有一种强调色**。绿色不用于大面积背景；赭色只用于"需要读者注意但不等同错误"的提示。

### 5.2 字阶（9 级，无中间值）

| 令牌 | 手机 | 桌面 | 用途 |
| --- | --- | --- | --- |
| `--t-11` | 11 | 11 | 栏目标签、编号标签、图注授权、页脚 |
| `--t-13` | 13 | 13 | 元信息、图注、按钮小字 |
| `--t-15` | 15 | 15 | 正文、列表标题、输入框 |
| `--t-17` | 17 | 17 | 回答、指标说明、桌面导语 |
| `--t-20` | 20 | 20 | 区块标题、下一篇 |
| `--t-24` | 24 | 24 | 详情 H1（手机）、桌面品牌字 |
| `--t-30` | 30 | 30 | 发现页主张（手机）、详情 H1（桌面） |
| `--t-38` | — | 38 | 页面大标题 |
| `--t-48` | — | 48 | 桌面发现页主张 |

正文行高 1.85–1.9；标题 1.3–1.5；字距：中文标题 0.01em，全大写标签 0.2em。**禁止 9px、10px、11.5px、12.5px 这类中间值**，原先 40 种字号收敛为 9 种。

### 5.3 间距（8 基数 + 4 半档）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`（`--s-1` … `--s-24`）。页面左右留白：手机 20px，桌面 40px。

### 5.4 形状

- 圆角只有两种：输入框/说明块 `4px`，胶囊 `999px`。不再使用 8/10/12/13/14/16/20/22/26px。
- 无阴影、无渐变、无毛玻璃。层级只靠色阶与 1px 线。
- 触控目标 ≥ 44×44px。

### 5.5 图标与插图

- 图标统一 Lucide，默认 `stroke-width: 1.7`，尺寸 15/17/20/21。
- 器官插图使用现有 `public/media/*.png`，不裁切、不改色；必须带 `alt` 与图注授权。
- 分享卡片沿用现有实现，配色改用本节令牌。

## 7. 响应式与无障碍

- 断点：`≤768px` 手机（单列、TabBar），`769–1100px` 平板（单列、页头居中），`≥1101px` 桌面（正文列 + 330px 右栏）。
- 320px 起不横向溢出；放大字号到 200% 时结构不塌。
- 所有正文颜色对比度 ≥ 4.5:1；发丝线不承担唯一信息载体。
- 焦点环 2px `--accent`，偏移 2px；动效遵循 `prefers-reduced-motion`。
- 无 JS 时正文、目录、来源可直接阅读。

## 9. 长文版式的取舍

- **图解是内联 SVG，不是图片文件。** 外部 SVG 无法使用页面的 `@font-face`，中文标签会回退到设备字体；内联 SVG 还能让文字可选中、可被屏幕阅读器读取。图注、简化边界和来源角标与图片方案一致。
- **目录只列分节，不列每个段落。** 长文最多 5 节 + 附录，目录因此控制在 7 项以内；超过 9 节需要重新考虑信息架构，而不是继续加链接。
- **「常见问题」必须是真的问题。** 内容规则禁止 `如何理解…？` 这类由指标名称自动生成的问句，也禁止答案与正文逐字重复。
- **故事不使用指标模板。** 故事页没有指标分工和过程链，正文更早出现第一张图；它靠叙事推进，而不是套用统一五段。

## 10. 与产品蓝图的关系

本规范不新增功能，只重排既有内容与既有能力：不引入评论、账号、推荐算法、无限流，也不新增医学结论。蓝图中的"发现页主推一篇 + 相关作品"由 `FeatureEntry` + `IndexRow` 承载；"手机先单列"由断点规则保证；"不先上多栏底栏"沿用现有 3 项导航。
