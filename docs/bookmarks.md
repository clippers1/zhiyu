# 收藏管理

版本：`0.0.1-beta.9`。

## 本轮范围

- 指标详情和器官详情均可收藏，导航徽标为两类本地条目的总数，包括暂不可用条目。
- 收藏页按指标/器官切换，支持现有关键词检索、内容分类筛选与分页。默认进入指标分类，兼容原有使用路径。
- 单项移除后可撤销最近一次移除；撤销提示仅留在当前收藏页面，不跨刷新保留。
- 清空仅针对确认弹窗打开时选定的那类条目，二次确认后执行，不影响另一类收藏和阅读记录，也不删除其他标签页新增且不在确认列表中的条目。
- 已撤回或当前频道未开放的内容不生成阅读链接，也不显示旧正文；保留本地标识，可手动移除。只在完整查询成功后判断不可用，网络失败可重试。

这轮的“分类管理”是类型切换与既有内容分类筛选，不包含自定义文件夹、账号、跨设备同步或批量导入导出。

## 本地存储与隐私

旧指标收藏继续使用 `zhiyu-saved` 字符串数组，器官使用独立的 `zhiyu-saved-organs` 数组，避免相同标识跨类型冲突。仅保存内容 ID，不保存文章正文、搜索词或医学判断。读取时去重并校验标识；不在页面打开时重写、清空或迁移旧存储。

打开收藏页会向当前内容频道查询这些 ID 的可用状态；关键词检索仍由已有内容接口处理。因此“本地保存”不意味着没有网络请求。服务端 HTML 不包含读者个人收藏，收藏页继续 noindex；禁用 JavaScript 时明确提示无法查看或管理本地收藏。

写入在点击操作时同步执行，避免紧接页面导航时丢失变更。普通跨标签页修改与浏览器存储清空事件会同步；每次变更先读取最新数据。localStorage 不提供跨标签页事务，不承诺极短时间内完全同时编辑的冲突合并。

读取或写入失败会提示“本次更改可能无法保存”，允许当前页面内临时增删；页面刷新或 SSR 整页导航后可能丢失临时状态。若移除失败且需要清除旧数据，应使用浏览器的站点数据清理功能。正常情况下清除站点数据也会丢失收藏，暂无云端恢复。

## 数据与验证

沿用现有正式/演示 API 权限，无数据库迁移、无内容重新发布。每批最多 200 个 ID，按接口每页最多 24 条读取完整结果后再呈现分页；后续批次失败时不返回不完整的可用性判断。大规模收藏会增加请求数，未来视实际使用规模决定是否新增专用批量接口。

测试命令：`npm run test:bookmarks`；浏览器检查使用 `node scripts/bookmarks-smoke.mjs`，可设置 `PLAYWRIGHT_BASE_URL` 与 `TEST_SSR=true` 验证 SSR 站点。覆盖旧数据兼容、同 ID 类型隔离、搜索、移除/撤销、确认清空、跨标签页清空、205 条分页与批次、请求失败重试、存储失败和移动布局。

本版交付检查：25 项前端规则测试、Vite/Next 构建与 TypeScript 通过；静态浏览器的收藏、既有主流程、阅读、路线、场景入口与搜索回归通过；隔离数据库的 6 组服务端渲染检查及 SSR 收藏/既有 SSR 浏览器回归通过。浏览器测试不替代真实用户任务观察。

收藏能力不代表医学内容已完成专业审校；下一项仍按路线图推进阅读位置恢复。
